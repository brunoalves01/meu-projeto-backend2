# Meu Projeto Backend 2 🚀

Treino para de praticar a inicialização e configuração do zero de um ambiente backend utilizando **Node.js** e **TypeScript**.

---

## 🛠️ Tecnologias Utilizadas

* **Node.js** — Ambiente de execução JavaScript no servidor
* **TypeScript** — Superset JavaScript para tipagem estática e prevenção de erros
* **npm** — Gerenciador de pacotes
